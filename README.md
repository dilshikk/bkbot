# bkbot

Telegram-бот выдачи актуального зеркала с админ-панелью.

## Возможности
- Выдача активного зеркала, резервное зеркало, учёт переходов
- Обязательная подписка на каналы
- Раздача приложения (APK)
- Команды в группах: `/link` — зеркало, `/app` — приложение
- Рассылки (сразу и по расписанию)
- Health-check зеркал и переключение по расписанию
- Баны, режим техработ, антиспам, ежедневная статистика

## Требования
- Python 3.11+
- PostgreSQL
- Redis

## Запуск
```bash
pip install -r requirements.txt
cp .env.example .env      # заполнить значения
alembic upgrade head
python main.py
```

Бот должен быть администратором во всех обязательных каналах,
иначе проверка подписки для этих каналов пропускается.

## Команды в группах
Добавьте бота в группу — он ответит на команду реплаем:
- `/link` (или `/link@имя_бота`) — активное зеркало с кнопками «Перейти» и «Поделиться»
- `/app` (или `/app@имя_бота`) — APK-файл (если приложение включено в админке)

На всё остальное в группах бот не реагирует. Особенности:
- Подписка на каналы в группах не проверяется, участники группы
  не добавляются в базу пользователей и не получают рассылки.
- Одинаковая команда в одном чате выполняется не чаще раза в
  `GROUP_COMMANDS_COOLDOWN` секунд (лишние вызовы игнорируются).
- `GROUP_COMMANDS_CHAT_IDS` ограничивает список групп, `GROUP_COMMANDS_ENABLED=false`
  выключает функцию полностью.
- При включённом privacy mode Telegram не всегда доставляет боту `/link` без
  упоминания. Надёжнее сделать бота администратором группы или использовать
  `/link@имя_бота` (меню команд подставляет его автоматически).
- У бота должно быть право отправлять сообщения, фото и файлы в группе.
